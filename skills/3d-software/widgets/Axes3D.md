# AxesWidget

Ages shows three axes that can be changed with mouse.
They show both positive and negative axes and axes letters.

## Input

Mouse - can grab and rotate or click on axis letter that moves from perspective to orto

Keyboard - numpad keys change the orto like in blender,
Num 1 - ortho X
Num 3 - ortho Y
Num 9 - ortho Z 
Num 4,6 - same rotation like in blender
Num 2,8 - same rotation like in blender
 
Touch - same as mouse 

## Theme

X - red
Y - green
Z - blue
