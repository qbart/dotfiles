# Canvas

Canvas renders 3D content for editor based on Scene model.

## Input

Mouse:
LMB - Select element or Select Box
MMB - Rotate like in blender
Wheel - Zoom
Shift + Middle - Pan view 

Keyboard - numpad keys change the orto like in blender,
Num 1 - ortho X
Num 3 - ortho Y
Num 9 - ortho Z 
Num 4,6 - same rotation like in blender
Num 2,8 - same rotation like in blender
 
Touch - same as mouse
